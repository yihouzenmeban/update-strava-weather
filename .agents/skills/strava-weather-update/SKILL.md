# Strava 活动天气标注

在仓库根目录运行本地命令；首次配置见 [README 的首次配置](../../../README.md#首次配置)，山峰库准备见 [离线山峰库说明](../../../peaks/README.md)。无需 Strava MCP，不读取或输出配置密钥和 token。

## 默认流程

用户要求同步新增活动天气时，只执行一次：

```bash
./update_strava_weather.sh sync
```

不要先调用 `list`、`get`、`streams`，也不要自行查天气、计算范围、选择 emoji 或猜山名；这些步骤由脚本完成。脚本默认直接写入缺失天气，无需额外确认。

已处理 ID 不重新入队，室内及 Virtual 活动跳过；未处理但已有天气的活动只更新山峰，保留天气和标题。山峰来自离线库，旧 summitbag 数据行会清理，空结果也可能删除旧行。范围、缓存与合并规则见 [README 的用法](../../../README.md#用法) 和 [山峰匹配](../../../README.md#山峰匹配)，不承诺保留旧 summitbag 或自动刷新已处理活动。

## 按用户意图选择参数

下列 `123` 为虚构 ID，必须替换为用户指定的 ID：

```bash
# 指定活动，不查最新列表；已处理 ID 仍跳过
./update_strava_weather.sh sync --activity-id 123

# 用户要求先看结果
./update_strava_weather.sh sync --dry-run

# 用户指定日期补扫，日期按 UTC，包含起止当天
./update_strava_weather.sh sync --since 2026-10-01 --until 2026-10-15

# 用户要求补齐全部历史；已有处理记录的 ID 仍跳过
./update_strava_weather.sh sync --all

# 用户明确要求重算，或修复已处理活动中被手动删除的天气
./update_strava_weather.sh sync --activity-id 123 --force

# 用户指定自定义描述模板；相对路径以仓库根目录为准
./update_strava_weather.sh sync --template weather.custom.txt

# 用户要求关闭山峰匹配与山峰行修改（参数沿用旧名称）
./update_strava_weather.sh sync --no-reorder-summitbag
```

`--activity-id`、`--since`、`--all` 互斥，`--until` 只能与 `--since` 配合；显式范围不处理范围外积压或推进默认扫描进度。`--force` 重算整个所选范围的天气和标题，仍跳过室内活动，失败后重算标记会保留；不要擅自扩大范围。用户仅要求刷新已处理活动的山峰时，应说明当前没有独立的仅山峰刷新参数，不能把 `--force` 解释成只改山峰。多个指定 ID 逐个运行并汇总，不额外扫描列表。

`--dry-run` 不写活动或同步状态，但会读取真实 API、消耗配额并更新本地用量。缺少离线库时按上述准备说明处理，不能把天气成功当作山峰已匹配成功。

## 错误处理与结果

- 无 GPS：询问活动地点；获得可靠坐标后运行 `sync --activity-id ID --latitude LAT --longitude LNG`，不猜测常用地点。坐标覆盖只用于天气，不能替代山峰轨迹。
- 授权失效：提示用户运行 `./update_strava_weather.sh login`；手动 `auth` 从标准输入读取授权码，不把凭据放进命令行参数。
- 活动处理上抛授权失败或 429：本轮停止，报告原因和剩余队列，不连续重试。山峰轨迹获取路径会捕获此类错误并降级继续，应报告警告和山峰未完成情况，不将成功退出当作全部功能成功。
- 活动处理返回 404：脚本记为 `gone` 并移出队列，不重复重试；可能是不存在或无访问权限，不断言已删除。预览不持久化此变更。
- 配额预留暂停（退出码 `4`、`⏸️`）：报告暂停和剩余任务，等待窗口恢复；不立即循环重试，也不改用单 ID 绕过批量保护。计数范围见 [API 用量与配额](../../../README.md#api-用量与配额)。
- 普通单条失败：其它活动继续处理，报告成功数量、失败 ID 和原因；不要将部分失败说成全部成功。
- 历史补扫分页失败：提示重跑原补扫命令，不能声称未扫描的历史已经入队。
- 处理记录损坏：报告错误，不自动清空已有记录。
- 已处理、已有天气、室内或并发跳过：按实际输出简短报告原因；已有天气仍可能更新山峰。
- 更新成功：展示脚本输出的最终标题和描述；仅更新山峰时说明天气与标题未重算。保留失败退出码。

默认扫描范围及恢复语义统一见 README；定时运行见 [运行模式](../../../README.md#运行模式)，仅在用户要求时配置。日志和处理记录均只留本地。
